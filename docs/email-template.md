# 산업 브리핑 이메일 형식

이 문서는 현재 CLI가 생성하는 MVP 이메일 형식을 기록합니다. 운영용 콘텐츠·발송 시간·수신자 승인을 뜻하지 않습니다. 자동 요약이나 기사 본문은 포함하지 않습니다.

**제목:** `[산업 브리핑] YYYY-MM-DD`
**테스트 수신자:** `nuguri12@gmail.com` (자기 계정으로 보내는 기능 검증용)

```text
반도체·자동화 장비 산업 브리핑
수집 시각: {KST 수집 시각}
조회: {검색어}
기사 {건수}건 / 제외 {건수}건
GDELT 관측 시각은 원문 발행 시각과 다를 수 있습니다.
GDELT: {ok/failed}
MSIT RSS: {ok/failed}
{부분 수집 또는 조회 상한 안내 — 해당하는 경우}

1. {기사 제목}
수집 소스: {GDELT/MSIT RSS}
출처: {출처}
{관측 시각/발행 시각/발행일}: {시각 또는 날짜}
원문: {링크}
```

- 출처와 원문 링크를 유지합니다. GDELT 시각은 관측 시각으로, 날짜만 제공하는 RSS 항목은 발행일로 표시합니다.
- RSS 설명, 언론사 본문, AI 생성 요약은 현재 이메일에 넣지 않습니다.
- 소스 일부가 실패하면 확인된 기사와 실패 상태를 표시합니다. 발송 가능한 기사가 없으면 발송하지 않습니다.
- `--email-check`는 위 메시지를 검증하고 미리보기만 출력합니다. 실제 전송에는 `--send`, `--to`, `--delivery-id`, SMTP 설정이 필요하며 로컬 SQLite 이력으로 중복 발송을 막습니다.
- 수신자와 운영 일정은 테스트 수신자와 별도로 확정해야 합니다.
